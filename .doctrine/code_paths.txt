# What counts as a CODE change in this repository — consumed by TASK-ACCEPTANCE.
# One extended regular expression per line, matched against staged paths. See .doctrine/README.md.
#
# ⭐ WHY THIS FILE EXISTS, measured rather than assumed. The built-in default,
#     (^|/)(crates|src|scripts)/|\.(rs|sh)$|(^|/)Makefile$
# is wrong for this project in BOTH directions, over all 125 tracked files:
#
#   OVER-MATCH  28 files of mdBook prose under `docs/book/src/` match on the `src/` segment.
#               mdBook's source directory is not a source tree. Demanding a full code-acceptance
#               checklist for a paragraph of prose is how a gate teaches its authors to waive it.
#   UNDER-MATCH 8 files that genuinely govern behaviour do not match at all:
#               doctrine/readme_routes.tsv, docs/provenance/*/dispositions.tsv (gate DATA — the
#               ceilings and dispositions the checks enforce), .doctrine/* (these seams),
#               .githooks/* (the local gate), Cargo.toml and Cargo.lock.
#
# The list below is an ALLOW-LIST: a staged path that matches is a code change. The test for
# adding a line is "can editing this alone change what the repository DOES?" — which is why the
# gate's own data and its own seams are in, and why prose is out.

# Rust workspace
(^|/)crates/
\.rs$
^Cargo\.(toml|lock)$
^rust-toolchain\.toml$
(^|/)Makefile$

# Executable discipline: any shell script, wherever it lives, plus the hooks and CI.
# ⛔ `\.sh$` is deliberately unanchored. A first cut wrote `^scripts/.*\.sh$`, which silently
# dropped the two executable probe drivers under `docs/tasks/artifacts/` — and those emit the
# `probes: N pass / N fail` line declared in `evidence_tokens.txt`, so editing one changes what
# evidence an author is allowed to cite. The over-match this file exists to fix was never about
# `.sh`; it was about the `src/` path segment.
\.sh$
^scripts/
^knowledge-map/scripts/
^\.githooks/
^\.github/workflows/

# Gate SEAMS and gate DATA — editing either changes a verdict without touching a script
^\.doctrine/
^doctrine/.*\.tsv$
^docs/provenance/[^/]+/dispositions\.tsv$
