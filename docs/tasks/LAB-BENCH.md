## Goal

A person can *feel* the laboratory while it is being built: run a tracked guest and watch it
execute — pc, instruction, register writes, traps — and flip a mutation to watch the
differential catch it. Two surfaces, one engine, no frameworks, no new Rust dependencies:
the CLI demo (`semulith demo`) and the browser bench (`bench/index.html` over the wasm build).

## Non-Goals

- No debugging features (breakpoints, watchpoints) — that is a P2+ surface decision.
- No server, no build chain beyond cargo + one copy script; the page is static files.
- No wasm-bindgen or any foreign dependency — the wasm exports are std-only `extern "C"`
  (RUST-01: production foreign-language dependencies require a recorded decision; staying
  std-only keeps that decision unnecessary).
- No new tracked artifacts from the build: the copied `.wasm` under `bench/` is gitignored,
  regenerated by `scripts/build_bench.sh`.

## Acceptance Criteria

1. `semulith demo [--guest NAME] [--mutate NAME] [--json]` prints the full observation trace
   of any tracked guest under the real or a mutated model, with the expectation verdict or the
   first divergence named.
2. `bench/index.html` in a browser runs any guest × any exposed mutation and renders both
   traces with the first divergence highlighted — from the same engine, via wasm.
3. The bench engine is verified without a browser: a node smoke instantiates the wasm module
   headlessly and asserts a clean run meets the pinned expectations and a mutated run
   diverges where the `.9` suite says it must.
4. `make bench` builds the module; the `PORT-WEB` gate stays green.

## Decisions

- `2026-09-28`: the bench is a **static page over std-only wasm exports**, not a framework
  app. RUST-01 makes every foreign dependency a recorded decision; `extern "C"` exports on the
  existing crates are not a dependency at all. The page re-implements nothing: the engine is
  the same `run`/`mutate` code the commit gate tests.
