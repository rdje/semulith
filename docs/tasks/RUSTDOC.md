## Goal

The workspace's public API reference is produced by rustdoc from the code, reachable from the project book, and
held by a gate: no broken or private intra-doc link and no invalid HTML in any doc comment, and the count of
undocumented public items never rises.

## Non-Goals

- No hand-written API reference beside rustdoc; prose chapters explain, rustdoc enumerates.
- No tracked HTML: the reference is built like the books (`make book`), never committed.
- No change to retained evidence: no Rust file and none of the generators below is a pinned input of the
  retained M case (measured 2026-10-23: 0 `crates/` paths pinned).

## Acceptance Criteria

1. `cargo doc --workspace --no-deps --offline` builds on every commit with the link and HTML lints denied, the
   gate's self-test fired RED on the real tree before registration.
2. The book links to the reference built in its output; the director reaches it from the book alone.
3. Undocumented public items are counted per crate and may only fall (a ratchet, as TABLE-ARITY).
4. Generated modules carry docs written by their generators, regenerated byte-exactly (DEF-GEN, STATE-GEN,
   GUEST-GEN stay green).
