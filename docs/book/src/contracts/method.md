# The method

`docs/METHOD.md` is the method this project uses to turn a specification into a model
definition an engine can be built from — written to be carried to a processor this project has
never modelled. The judgement calls are named (choosing the publication, classing the fact,
judging the authority, classifying the disagreement); everything else is kept mechanical, and
the document says which is which.
