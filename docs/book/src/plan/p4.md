# P4 — the Linux CPU profile

**Deliverable: the processor Linux actually needs, validated as a processor.**

Select a Linux-capable profile — provisionally RV64GC with an explicitly chosen privilege
revision, M/S/U modes, Sv39 translation, implemented CSRs, interrupt acceptance, counter
behaviour, and stated firmware and toolchain requirements. *Provisionally* is load-bearing:
the exact dependency closure is resolved before the profile is claimed, not assumed from the
letters.

## The new work

System transitions, page walks and their permitted side effects, protection, atomics, floating
point, instruction visibility, faults, and restart obligations — all implemented and
independently tested **in the laboratory environment**, not by booting something and seeing
whether it complains.

## The floating-point condition

Floating-point support is not included until a named Rust implementation has passed its own
qualification task: the exact target policy for rounding modes, flags, result bits,
conversions, NaN payloads and boxing; the ancestry inventory (shared SoftFloat lineage, target
specialization, thread-local versus global status handling, exact compiler and features); and
independent numeric fixtures.

If no suitable Rust implementation passes, the required subset is implemented in Rust and the
corresponding CPU capability is deferred until validated. There is **no silent native-float or
FFI fallback** — that would make the host's floating-point defaults into the guest's semantics.

## Sv39 translation and protection: `.3` underway (slices a–d, 2026-10-04)

The design brief (OQ-2 answered, a minimal TLB, translation as evaluator machinery,
walk accesses a boundary variant) executes in five checkpoints. Slice (a): the
profile's identity gains **Svade** — a translation needing an A/D PTE update raises
a page fault, never a hardware update — closing the dossier's OQ-2 on three
evidence legs (the pinned revision's two named schemes; the U54 precedent the Sv39
choice already cites; the observation discipline's pricing of the hardware-update
default). Svadu is not selected; the ISA string grows to
`rv64imafdc_zicntr_zicsr_zifencei_sstc_svade`. The Sail matched override flips
`Svade` to `true` — and the full 12-guest re-run measures the effect as exactly
zero (11/12 AGREE, baseline-identical). The generator's rv64gc path now refuses
the three descriptor constructs it used to ignore silently.

Slice (b): the translation machinery shell lands — a `translation.rs` beside
`privilege.rs` with the effective-mode computation (fetch uses the current mode,
data accesses use MPP when MPRV=1), satp.MODE dispatch (M-effective and Bare are
exact identity; Sv39 enters the walk as the next slice's named case), the
page-fault cause vocabulary, 16-bit fetch parcels that coalesce to exactly one
request whenever the translated addresses share one physical unit, and the
walk-access boundary kind entering the environment contract (8-byte physical,
read-only under Svade). The Bare-identity proof is byte-level: both engines drive
all 62 guests and 1,884 trace lines compare identical — the machinery changes
nothing an observer can see until software asks for Sv39.

Slice (c): the walk itself is live — the ten steps of §11.1.3.2 cited one by one
in the module: the canonical-address check, the per-level page-table reads through
the boundary's own walk-access kind (a fault there is the original access's fault,
never substituted), the reserved-encoding checks, superpage alignment, the
permission matrix with SUM/MXR, and Svade's page-fault-instead-of-update — with
the byte-level proof that a faulted walk never touches the page table. The
straddled instruction now fetches each half from its own page and joins them. And
the implicit-access requirement is amended honestly: the rv64gc catalogue never
carried the base record, so the amendment is a new authored record naming the
walk's implicit reads (and, under Svade, the absence of implicit writes).
Everything Bare remains byte-identical — 1,884 trace lines, both engines, all
62 guests.

Slice (d): the cache gets real. A minimal fully-specified TLB — 4 entries,
fully-associative, FIFO, ASID-tagged, keyed by 4 KiB page — sits between the access
and the walk, with the discipline the spec sanctions and nothing more: hits only
for translations valid since the last subsuming fence, faults never installed,
satp's mode and ASID changes visible immediately, staleness legal until a fence and
never after. SFENCE.VMA stops being a stated nop and does the four specified cases
through the semantics language itself (a new `tlb-invalidate` operator, so the
semantics data stays the one executable owner of every rule). The hidden-state
census carries the cache's parameters as data, and the generator refuses a document
silent about them. Everything Bare remains byte-identical — 1,884 trace lines,
both engines, all 62 guests.

Slice (e), part 1: the walk stops being a unit-test promise and becomes a corpus.
Fourteen sv39 guests build their own page tables in M, arm satp, drop to S (and U),
and falsify the machinery end to end — the happy-path translates at 4 KiB, 2 MiB and
1 GiB, each closing with the M-mode read-back of the very PTE the walk used,
byte-untouched because Svade forbids the update; the four fault guests walk every
failing step (non-canonical address, V=0, the reserved encoding, misaligned
superpages); the permission guests cover R/W/X, U with SUM and MXR, and a fetch
that page-faults; MPRV makes an M-mode load translate with MPP's mode while the
fetch provably does not; the TLB guest serves the stale mapping before the fence,
keeps the global entry across the ASID-selective fence, and tells the truth after
the full one; one instruction straddles two pages that map non-contiguously, and
the fetch joins its halves from two requests. Every expected value is derived from
the pinned chapters by a spec-side model — never copied from an engine run — and
the fetch-count witness learned to be declared: a fetch that faults in the walk
issues no request, a straddle issues two. Everything Bare remains byte-identical —
all 62 pre-slice guests, both engines.

Slice (e), part 2 — and the leaf closes: the matched experiment. Every sv39 guest
also runs under Sail 0.14 with the profile's own tracked configuration, and the
comparison is explicit on three dimensions: the architecture (the same
change-observation rule the corpus uses), the page-table walks themselves
(Sail's PTW trace against the specification-derived walk log, read-for-read at
the same addresses), and the TLB events (adds and flushes — the fence guest
shows the same seven adds and two flushes on both sides). Thirteen guests agree
outright; the fourteenth records one vocabulary convention — Sail judges the
A/D bits after the walk, the laboratory judges them at the walk's ninth step,
and the delivered trap is identical either way. The experiment caught one stale
fact of its own: the override's delegation mask predated page faults, so the
delegation guest's fault went to M on Sail — the mask is now the widest both
sides honor, proven verdict-neutral on the older corpus. The acceptance reads
as measured: a permission failure produces the correct fault, and the page
table's permitted side effect — under Svade, nothing at all — is exactly what
happens.

## Atomics and reservations: `.4` underway (slice a, 2026-10-04)

The design brief (the A fragment is Zaamo + Zalrsc's 22 forms; a minimal exact
reservation; the deterministic SC policy as data; an atomic bind) executes in six
checkpoints. Slice (a): the `rv_a`/`rv64_a` tables are re-pinned through the tracked
`extensions/` fetch route — the 22 forms (the nine AMOs and the lr/sc pair, each
`.W` and `.D`) that the pinned RVWMO chapter's Tables 6/7 enumerate exactly — and
`definitions/riscv/a.sexp` is generated from them, owning the `aq`/`rl` ordering
fields. The assembler learns the A machinery: the `.aq`/`.rl`/`.aqrl` mnemonic
suffix as the aq/rl FIELD VALUES (never table names; all four combinations assemble
— every aq/rl effect is defined "as viewed by other RISC-V harts", so at one hart
they decode and order nothing observable), and the `(rs1)` parenthesized-address
spelling for the lr/sc/amo shapes. 88 words (22 forms × 4 suffix combinations)
round-trip through spike-dasm exactly; every shape it cannot assemble is refused by
name. The pin exposed its own census's blind spot — the scope-vs-tables leg had
never collected a `rv64_*` table — fixed at root with the rv64i dossier's declared
"pinned for the fragment, not the scope" exclusion extended to the A tables until
the bind. The slot stays declared and the scope census stays 65: both grow only at
slice (e)'s atomic bind, one green commit.

Slice (b): the semantics language grows 40→43 forms. A RESERVATION contract block
states the one-hart rules once — the minimal exact reservation, physical-keyed; any
LR replaces, any SC clears, traps do not invalidate — and three operators carry the
policies the brief decided: `load-reserved`, `store-conditional` (yields the rd
code, 0/1, never spurious under the declared deterministic policy), and `amo` — one
operator for the closed nine, translating ONCE under the store/AMO rules (never a
load page fault; the decomposition into load-op-store would deliver the wrong fault
cause), the boundary shape a load followed by a store. `a.sem.sexp` covers all 22
forms, every rule locator-cited and resolving offline against the pinned A chapter.
Two measured design points: the AMO's operation is the funct5 literal (a bare
symbol would be refused as a phantom operand), and the closed set is RE-DERIVED from
the composed encodings; and the `Sem` variants emit exactly when the composition
composes `riscv/a` — the evaluator's exhaustive match is the `.2` slice-d wall, so
the tracked modules regenerate hash-only while the scratch composition lowers and
compiles standalone.

Slice (c): the reservation is hart state now — `reservation.rs` owns (physical
address, width, valid), the minimal conformant set, physical-keyed, with exactly
the spec's one-hart invalidation set: any LR replaces; any completed SC clears; a
trap clears nothing (measured on Sail 0.14: its cancellation fires on the completed
SC path only). The deterministic SC policy rides as data in `state.sexp` beside the
census candidate, and gen_state's census gate is generalised to refuse any carried
hart state the census does not declare. The evaluator arms exist and are proven in
scratch — 16/16 over the LR/SC pair and every must-fail cell, the AMO nine × `.W`/`.D`
with old-value rd sign-extended, the translated AMO faulting 15 never 13 on an
unreadable page, misaligned atomics taking cause 7 before translation, the
constrained loop succeeding on its first SC — and land tracked at the bind.

Slice (d): the corpus exists. Twelve staged guests cover the brief's families —
the nine AMOs × `.W`/`.D` with rd sign-extended at the word edge and the min/max
signedness disagreements, every aq/rl combination executed identically, register
overlaps, the LR/SC pairs and every one-hart must-fail (different address,
intervening SC, LR-replaces, width mismatch, SC-without-LR, a failed SC writing
nothing), a constrained loop closing on its first SC, misaligned atomics taking
cause 7 before translation, the translated AMO faulting 15 never 13, and an alias
cell proving the reservation physical-keyed. Every expectation is derived by a
spec-side model written from the pinned chapters and the declared policy — never
engine output — and every word assembled by the tracked assembler's A machinery;
the corpus runs 12 PASS / 0 FAIL through the slice-(c) scratch engine,
deterministic on re-run. The matrix rehearsal resolves all 28 cells with the new
guests riding the seven existing axes, and the coverage rehearsal reads 22/22 —
the bind's 87-form denominator is fully exercised in staging.

Slice (e) — **the bind**: one green commit makes A real. The slot becomes an
extension, the census dual edit grows 65 → 87 (the RVWMO Tables 6/7 enumeration),
`definition_rv64gc.rs` regenerates with the 22 forms and the three `Sem` variants,
the evaluator arms port byte-identical from the scratch proof, and the twelve
guests land tracked — the full 88-guest corpus executes green through the tracked
engine, with the slice-(c) proof re-run against it. The reservation and its
deterministic SC policy, and the misaligned-cause-7 choice, are profile decisions
with verbatim requirement and obligation mirrors. The fetch leg's scope-vs-tables
check flips on its own to 87 == 87, and every one of the 76 pre-bind guests runs
byte-identical against the parent engine (3,468 trace lines, `cmp` clean) — the
22 new forms are additive; the corpus never noticed. The profile now executes
atomics.
