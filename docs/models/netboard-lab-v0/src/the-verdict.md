# The composition verdict

The board's evidence is a **verdict**: every environment assumption in the accepted CPU
contract is matched to a named board or device guarantee, or the composition is rejected.
It is decided mechanically on every commit by the **BOARD-VERDICT** doctrine
(`scripts/check_board_verdict.sh` — the discharge over the composed catalogues, the
`satisfies` edges resolved, the four composition dispositions bound), and the authored
half below is the same file the dossier carries
(`profiles/netboard-lab-v0/COMPOSITION-VERDICT.md`), included — one owner, two readers.
