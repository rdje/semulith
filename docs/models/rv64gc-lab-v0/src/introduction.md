# Introduction and scope

`rv64gc-lab-v0` is the project's Linux-oriented **processor laboratory profile**.
This book describes its selected materials, the choices needed to turn them into a
machine, and the evidence still owed. Registration supplies a reviewable unit and
materials census; it does not authorize a processor release or Linux boot claim.

The canonical selection is `profiles/rv64gc-lab-v0/profile.sexp`: RV64I with
M/A/F/D/C, Zicsr, Zicntr, Zifencei, privileged Sstc and Svade; M/S/U; one hart;
little-endian; Sv39; IALIGN16/ILEN32. G alone does not select counters, a supervisor
timer, translation or firmware. The individual source chapters and profile
closure select them. H, PMP, V, Zihpm, Sv48/Sv57 and hardware A/D updates are
excluded. LP64D and SBI2.0 are declared software/firmware contracts, not services
silently supplied by the host.

Three questions must be answered separately:

| Question | Where to review the answer |
| --- | --- |
| Have the defining facts been acquired? | [Materials](materials.md), generated pin tables and `materials/category-needs.sexp`. `covered` means collection coverage. |
| What does the selected machine do? | Canonical profile, composed definitions, state and environment contract; [choices](gaps.md) and [method](methodology.md). |
| Is the complete processor accepted? | [Generated gate](evidence.md), structured evidence and [prospective policy](policy.md). Open axes remain open. |

The four materials fragments are generated by `scripts/gen_model_book.py`;
MATERIALS-BILL rejects drift and missing per-material limits. UNIT-BOOKS checks
that every registered unit has a buildable book. Those checks establish document
integrity, not semantic correctness. Every source identity and reference pin
below comes from the canonical dossier rather than an independently typed table.

A useful reading route is materials → choices → method → reference limits →
policy → gate. The project book's P4 chapters retain worked implementation and
contract experiments. The [historical capture](history.md) preserves corrected
dossier wording so that an earlier claim cannot silently become current evidence.
